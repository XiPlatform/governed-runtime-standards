# Changelog

## 1.0.0 (2026-09)

First public release of the Governed Runtime Standards and the reference implementation.

- Action Provenance Record 1.0: specification, JSON Schema, three conformance levels
- Action Approval Attestation 1.0: specification, JSON Schema, scope and coverage rules
- Governed Runtime Profile 1.0: twelve guarantees, three levels, conformance statement format
- Reference library `governed-runtime`: validation, canonicalisation, digests, MAC sealing and verification, per-scope chains, approval coverage; no runtime dependencies
- Worked examples and a test suite covering the normative rules
