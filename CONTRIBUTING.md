# Contributing

Issues and pull requests are welcome.

- Changes to a specification or a schema go through an issue first, so the reasoning is recorded before the change.
- Backwards-incompatible changes to a document shape are reserved for a new major version. Version 1.0 accepts clarifications and errata only.
- Keep the reference library free of runtime dependencies.
- Add or update a worked example and a test for any change to a schema or a normative rule.
- Run `npm run typecheck && npm test` before opening a pull request.
- Write specification text without em dashes; use commas, colons or full stops.
